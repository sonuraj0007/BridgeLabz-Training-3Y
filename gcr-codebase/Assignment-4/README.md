# JavaScript Assignment — Q1 to Q9

This ZIP contains one separate JavaScript file for each question. Browser-based tasks include a matching HTML file so you can run the form and DOM examples easily.

## Requirements
- Node.js for Q1, Q3, Q6, and Q9.
- A modern web browser for Q2, Q4, Q5, Q7, and Q8.
- No frameworks or external libraries.

## Run Node.js files
Open a terminal in this folder and run:
```bash
node Q1_Ecommerce_Product_Manager.js
node Q3_Library_Management_System.js
node Q6_Employee_Management_System.js
node Q9_Shopping_Cart_Total.js
```

## Run browser tasks
Open the matching HTML file in your browser:
- `Q2_Student_Form_Validator.html`
- `Q4_Custom_Form_Builder.html`
- `Q5_Movie_Ticket_Booking.html`
- `Q7_Login_Form_Validation.html`
- `Q8_Dynamic_Object_Updater.html`

Each HTML file loads its corresponding `.js` file from the same folder. Keep the HTML and JavaScript files together.

## Notes
- Q1 applies a 10% discount to one product, then filters products priced above ₹1000.
- Q3 demonstrates issuing a book by ISBN; change the ISBN in the example to test other books.
- Q4 builds the form from field definitions and returns entered values as an object.
- Q5 and Q2 show validation feedback in the page.
- Q6 calculates annual salaries and the total annual payout.
- Q9 accepts `SAVE20` and `DISC10` coupon formats, with the percentage encoded in the number.
