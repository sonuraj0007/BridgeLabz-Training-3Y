JavaScript Assignment — Q1 to Q10

Files:
- One separate .js file for each question.
- Each file uses console.log() for visible output.
- No external libraries are required.
- Run a file with Node.js, for example:
    node Q1_Dynamic_Data_Parser.js
- Q6 accepts an optional row count:
    node Q6_Pyramid_Pattern_Generator.js 7

Debugging:
Open a file in VS Code, click beside a line number to set a breakpoint, then press F5
(or Run > Start Debugging). Use the Variables, Watch, and Call Stack panels.

Notes:
- Q5 and Q8 include comments explaining the original traps; corrected code runs without
  intentionally stopping the whole script with a syntax/runtime error.
- Q8's non-strict comparison should be tested in a separate classic script without
  the "use strict" directive, because syntax errors can prevent an entire file from running.
